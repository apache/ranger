    Apache Ranger 2.4.0 release notes¶

    Apache Ranger 2.4.0 was released on March 30, 2023. The release adds fine-grained access control over nested data structures, a performance analyzer tool, official docker images on Docker Hub and multiple policy-model enhancements.

    Highlights¶

    • Nested structure plugin — fine-grained access control over nested structures such as JSON documents (RANGER-3828).
    • Performance and scalability analyzer tool for Ranger (RANGER-3852).
    • External user store retriever (RangerExternalUserStoreRetriever) for attribute-based policies (RANGER-3855); user attributes in masking expressions (RANGER-3865), default values when an attribute is missing (RANGER-3997).
    • Policy model — multiple resource sets in a policy (RANGER-3796), access-type categories such as Create/Read/Update/Delete/Manage (RANGER-4035), option to disable default policies per hierarchy (RANGER-4011), service-definition option to include the expression condition implicitly (RANGER-4117).
    • Administration — anonymous download of policies, roles and tags (RANGER-3623), non-admin users can manage roles (RANGER-3837), Ranger Admin client for non-Kerberized servers (RANGER-3856), requestId in logs via RangerMDCFilter (RANGER-4024).
    • Clients — Python client for Ranger KMS (RANGER-3982) and security-zone APIs in the Python and Java clients (RANGER-4080, RANGER-4101).
    • Trino — column masks and row filters with Trino SPI 376+ (RANGER-3983), views distinguished from tables (RANGER-3988).
    • Docker — official images published to Docker Hub (RANGER-4044), Ranger KMS in docker (RANGER-3978).
    • Dependencies — HBase 2.4.6 (RANGER-3971), Elasticsearch 7.10.2 (RANGER-3165), Solr 8.11.2 (RANGER-3818), Tomcat 8.5.86 (RANGER-4113), EclipseLink (RANGER-4107); builds on Apple Silicon (RANGER-3863).
