    Apache Ranger 2.3.0 release notes¶

    Apache Ranger 2.3.0 was released on July 9, 2022. The release adds new key-store back ends for Ranger KMS, richer policy-condition macros, Amazon CloudWatch as an audit store, Swagger UI for the REST API, and removes the Log4j 1 dependency.

    Highlights¶

    • Ranger KMS — master keys in Google Cloud HSM (RANGER-3569) and Tencent KMS (RANGER-3580); HSTS enforced on the SSL port (RANGER-3521).
    • Policy conditions and expressions — macros in row-filter and condition expressions (RANGER-3605), IS_IN_GROUP, IS_IN_ROLE, HAS_TAG (RANGER-3764) and IS_IN_ANY_GROUP, IS_IN_ANY_ROLE, HAS_TAGS (RANGER-3779), user and tag attributes in row-filter expressions (RANGER-3550), user attributes in policy resources (RANGER-3567), chained plugins support masking and row filtering (RANGER-3736).
    • Audit — Amazon CloudWatch Logs as an audit store and audit source (RANGER-2967, RANGER-3540), audit query size limited (RANGER-3518).
    • REST API — Swagger UI (RANGER-3389), tag endpoints promoted to /public/v2 (RANGER-3475), get or delete policies by GUID (RANGER-3439), 403 for authenticated but unauthorized clients (RANGER-3619).
    • UserSync — wildcards, group short names and lists of memberof DNs in the user search filter (RANGER-3630).
    • Solr plugin — fine-grained authorization for Solr admin objects (RANGER-3628, RANGER-3649).
    • Security — Log4j 1 removed (RANGER-3498), Log4j 2 upgraded to 2.17.1 (RANGER-3579), password policy updates (RANGER-3624, RANGER-3687), Spring 5.3.18 (RANGER-3691), Kerberos browser login (RANGER-2704).
    • Docker — multi-stage Dockerfile (RANGER-3738), UserSync and TagSync containers (RANGER-3585), MySQL option (RANGER-3686), containers run as ranger (RANGER-3658).
    • Dependencies — Kafka 2.8 (RANGER-3459), Storm 1.2.4 (RANGER-3561), Kylin 3.1.3 (RANGER-3698), Tomcat 8.5.78 (RANGER-3693); Trino plugin built with JDK 11 (RANGER-3755).
