    Apache Ranger 2.8.0 release notes¶

    Apache Ranger 2.8.0 was released on March 1, 2026. The release introduces the authz-api and authz-embedded modules, service-managed ACLs in the policy engine, Kerberized Solr audit support in the installers, and many dependency upgrades and bug fixes.

    Highlights¶

    • Authorization API modules — new authz-api (RANGER-5309) and authz-embedded (RANGER-5312) modules define a component-neutral authorization request/response model and an embedded authorizer.
    • Policy engine support for service-managed ACLs (RANGER-5369) and synchronous policy-cache download for testing plugins (RANGER-5230).
    • Kerberized Solr audit — Admin and plugin installers accept configuration for a Kerberos-protected Solr audit destination (RANGER-5382, RANGER-5383); the audit UI can query Kerberized Solr (RANGER-5384).
    • Authentication — RangerRESTClient can fetch a JWT when one is available (RANGER-5475); clients can reach secure API endpoints in non-Kerberos environments (RANGER-5488).
    • Audit filters can exclude by resource name (RANGER-5315, RANGER-5325).
    • Operations — change the log level without a restart (RANGER-5266), last login date and time on the home page (RANGER-5271), Ozone authorizer support for AssumeRole (RANGER-5393).
    • Dependencies — Hadoop 3.4.2 (RANGER-5467), Kafka 3.9.1 (RANGER-5457), Tomcat 9.0.113 (RANGER-5426), Jetty 9.4.57 (RANGER-5460), Elasticsearch 7.17.29 (RANGER-4939), hadoop-common replaced by smaller dependencies (RANGER-5478), migration from commons-lang 2.6 to commons-lang3 (RANGER-5391).
    • Security fixes — XML External Entity injection (RANGER-5477), server version disclosure in Ranger KMS (RANGER-5416), users with names similar to admin/keyadmin could query those accounts (RANGER-5342).
    • Docker — Kerberos support in the docker setup (RANGER-4898), volume mounts for service and plugin configuration (RANGER-5396, RANGER-5401), Ranger authorization for Solr (RANGER-5451).
