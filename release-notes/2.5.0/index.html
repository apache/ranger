    Apache Ranger 2.5.0 release notes¶

    Apache Ranger 2.5.0 was released on August 8, 2024. This is a large release: the Admin UI moves to React, JDK 11 and 17 builds are enabled, and the policy engine, security zones, KMS and docker setup receive many enhancements.

    Highlights¶

    • React Admin UI becomes the default Admin UI; the Backbone UI still ships as the classic UI (RANGER-3537, RANGER-4033, RANGER-4138, RANGER-4253); the "Switch to latest UI" toggle is removed (RANGER-4834).
    • Policy model — validity periods per policy item (RANGER-3815), multiple resource sets in one policy in the UI (RANGER-4010), SELF_OR_PREFIX resource matching scope (RANGER-4165), user and group attributes such as syncSource and emailAddress in ABAC expressions (RANGER-4389), plugins can use user-group mappings from Ranger Admin (RANGER-4391).
    • Security zones — roles as zone admins and auditors (RANGER-4274, RANGER-4280), incremental zone updates and resource pagination (RANGER-4398), zones without any service (RANGER-4286), REST API to find the zone for a resource (RANGER-4175).
    • New APIs and tools — roles import/export (RANGER-4025), force delete of users and groups (RANGER-4230), retention settings for x_auth_sess and x_trx_log (RANGER-4255, RANGER-4353), plugin memory sizing tool (RANGER-4303), service-headers API (RANGER-4533).
    • Ranger KMS — health metrics (RANGER-4047), AWS KMS as master-key provider (RANGER-3998), no master-key regeneration on restart (RANGER-3927).
    • Authentication — common authentication module (RANGER-3727), JWT filter in Ranger Admin (RANGER-3739) with doAs support (RANGER-4371).
    • Metrics — common metrics module with Admin metrics (RANGER-4152), Tomcat metrics (RANGER-4196).
    • Plugins — Kafka authorizer based on KIP-504 (RANGER-3231), combined HDFS authorization calls (RANGER-4817), HBase 2.6.0 (RANGER-4857), fewer Hive metastore calls (RANGER-4741), Trino docker setup (RANGER-4734), Ozone resource lookup (RANGER-2846).
    • Build and CI — GitHub Actions CI (RANGER-4072), JDK 11 and 17 builds (RANGER-4752), HikariCP connection pool (RANGER-2895), Hadoop 3.3.3 (RANGER-4807), ZooKeeper 3.9.2 (RANGER-4873), Solr 8.11.3 (RANGER-4870).
