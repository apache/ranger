# Apache Ranger 2.1.0 release notes

Apache Ranger 2.1.0 was released on September 3, 2020. The release adds plugins for Presto, Kudu and Schema Registry, Elasticsearch as an audit store, Ranger Admin high availability, Java and Python client libraries, Java 11 support and the first docker setup.

## Highlights

- **New plugins** — Presto ([RANGER-1784](https://issues.apache.org/jira/browse/RANGER-1784), [RANGER-2754](https://issues.apache.org/jira/browse/RANGER-2754)), Kudu ([RANGER-2683](https://issues.apache.org/jira/browse/RANGER-2683)), Schema Registry ([RANGER-2748](https://issues.apache.org/jira/browse/RANGER-2748)); Solr document-level authorization ([RANGER-2393](https://issues.apache.org/jira/browse/RANGER-2393), [RANGER-2723](https://issues.apache.org/jira/browse/RANGER-2723)).
- **Audit** — Elasticsearch as an audit destination ([RANGER-676](https://issues.apache.org/jira/browse/RANGER-676)), audit-exclude users and a blacklist for audits ([RANGER-2669](https://issues.apache.org/jira/browse/RANGER-2669), [RANGER-2780](https://issues.apache.org/jira/browse/RANGER-2780), [RANGER-2829](https://issues.apache.org/jira/browse/RANGER-2829)),
  optional GUID per audit record ([RANGER-2869](https://issues.apache.org/jira/browse/RANGER-2869)).
- **High availability** — Ranger Admin HA ([RANGER-2052](https://issues.apache.org/jira/browse/RANGER-2052)), plugins and UserSync work with HA without a load balancer ([RANGER-2555](https://issues.apache.org/jira/browse/RANGER-2555), [RANGER-2591](https://issues.apache.org/jira/browse/RANGER-2591), [RANGER-2592](https://issues.apache.org/jira/browse/RANGER-2592)).
- **Ranger KMS** — Azure Key Vault as master-key store ([RANGER-2497](https://issues.apache.org/jira/browse/RANGER-2497)), re-encryption APIs ([RANGER-2616](https://issues.apache.org/jira/browse/RANGER-2616)).
- **Client libraries** — Java ([RANGER-2862](https://issues.apache.org/jira/browse/RANGER-2862)) and Python ([RANGER-2927](https://issues.apache.org/jira/browse/RANGER-2927)) clients for the REST API; see [client interface](../features/client-interface/intro.md).
- **Policy engine** — plugin capability/compatibility model ([RANGER-2625](https://issues.apache.org/jira/browse/RANGER-2625)), incremental tag updates ([RANGER-2510](https://issues.apache.org/jira/browse/RANGER-2510)), formal super users ([RANGER-785](https://issues.apache.org/jira/browse/RANGER-785), [RANGER-2829](https://issues.apache.org/jira/browse/RANGER-2829)),
  refactored policy engine and resource trie ([RANGER-2652](https://issues.apache.org/jira/browse/RANGER-2652), [RANGER-2651](https://issues.apache.org/jira/browse/RANGER-2651)).
- **UserSync** — additional user and group attributes from AD/LDAP with a REST API to download them ([RANGER-2697](https://issues.apache.org/jira/browse/RANGER-2697), [RANGER-2632](https://issues.apache.org/jira/browse/RANGER-2632)).
- **Platform** — Java 11 support ([RANGER-2575](https://issues.apache.org/jira/browse/RANGER-2575)), Python 3 scripts ([RANGER-2759](https://issues.apache.org/jira/browse/RANGER-2759)), display names for services and service definitions ([RANGER-2590](https://issues.apache.org/jira/browse/RANGER-2590)),
  build produces a single `.tar.gz` archive ([RANGER-2980](https://issues.apache.org/jira/browse/RANGER-2980)).
- **Docker** — first `dev-support/ranger-docker` setup to build Ranger and run Admin, HDFS, HBase, Kafka and YARN ([RANGER-2960](https://issues.apache.org/jira/browse/RANGER-2960), [RANGER-2961](https://issues.apache.org/jira/browse/RANGER-2961), [RANGER-2969](https://issues.apache.org/jira/browse/RANGER-2969),
  [RANGER-2971](https://issues.apache.org/jira/browse/RANGER-2971), [RANGER-2974](https://issues.apache.org/jira/browse/RANGER-2974), [RANGER-2975](https://issues.apache.org/jira/browse/RANGER-2975)).
