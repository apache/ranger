# Apache Ranger 2.0.0 release notes

Apache Ranger 2.0.0 was released on August 7, 2019. The first 2.x release moves Ranger to Hadoop 3, Hive 3 and HBase 2, and introduces security zones, roles, policy-level conditions, incremental policy updates, and plugins for Ozone and Elasticsearch.

## Highlights

- **Security zones** — partition a service's resources into zones with their own administrators and auditors ([RANGER-2232](https://issues.apache.org/jira/browse/RANGER-2232), [RANGER-2379](https://issues.apache.org/jira/browse/RANGER-2379), [RANGER-2387](https://issues.apache.org/jira/browse/RANGER-2387),
  [RANGER-2347](https://issues.apache.org/jira/browse/RANGER-2347)); see [security zones](../features/sec-zone/intro.md).
- **Roles** in Ranger policies ([RANGER-2414](https://issues.apache.org/jira/browse/RANGER-2414)) with Hive SQL role commands ([RANGER-2425](https://issues.apache.org/jira/browse/RANGER-2425)).
- **Policy model** — conditions at policy level ([RANGER-2354](https://issues.apache.org/jira/browse/RANGER-2354)), policies that implicitly deny all other accesses ([RANGER-2507](https://issues.apache.org/jira/browse/RANGER-2507), [RANGER-2517](https://issues.apache.org/jira/browse/RANGER-2517)), custom
  conditions for access-from-cluster, cluster type and tag presence ([RANGER-2436](https://issues.apache.org/jira/browse/RANGER-2436), [RANGER-2467](https://issues.apache.org/jira/browse/RANGER-2467), [RANGER-2465](https://issues.apache.org/jira/browse/RANGER-2465), [RANGER-2494](https://issues.apache.org/jira/browse/RANGER-2494)), incremental policy updates ([RANGER-2341](https://issues.apache.org/jira/browse/RANGER-2341)).
- **New plugins and service definitions** — Ozone ([RANGER-2325](https://issues.apache.org/jira/browse/RANGER-2325)), Elasticsearch ([RANGER-2170](https://issues.apache.org/jira/browse/RANGER-2170)), ABFS ([RANGER-2209](https://issues.apache.org/jira/browse/RANGER-2209)), NiFi Registry ([RANGER-2157](https://issues.apache.org/jira/browse/RANGER-2157)), Presto ([RANGER-2395](https://issues.apache.org/jira/browse/RANGER-2395)).
- **Platform** — Hadoop 3.0.0 / 3.1.1 ([RANGER-1935](https://issues.apache.org/jira/browse/RANGER-1935), [RANGER-2432](https://issues.apache.org/jira/browse/RANGER-2432)), Hive 3.0 ([RANGER-2148](https://issues.apache.org/jira/browse/RANGER-2148)), HBase 2.0 ([RANGER-2151](https://issues.apache.org/jira/browse/RANGER-2151)), Kafka 2.0.0 with delegation-token and cluster
  resources ([RANGER-2210](https://issues.apache.org/jira/browse/RANGER-2210), [RANGER-2221](https://issues.apache.org/jira/browse/RANGER-2221), [RANGER-2222](https://issues.apache.org/jira/browse/RANGER-2222)), Atlas 2.0.0 ([RANGER-2431](https://issues.apache.org/jira/browse/RANGER-2431)), Solr 7.7 with bootstrapping from Ranger ([RANGER-2345](https://issues.apache.org/jira/browse/RANGER-2345), [RANGER-2324](https://issues.apache.org/jira/browse/RANGER-2324)), JDK 11 compilation ([RANGER-2317](https://issues.apache.org/jira/browse/RANGER-2317)).
- **Ranger KMS** — KeySecure HSM integration ([RANGER-2331](https://issues.apache.org/jira/browse/RANGER-2331)).
- **Admin** — `doAs` in the portal and REST API ([RANGER-2049](https://issues.apache.org/jira/browse/RANGER-2049)), Knox trusted proxy ([RANGER-2281](https://issues.apache.org/jira/browse/RANGER-2281), [RANGER-2443](https://issues.apache.org/jira/browse/RANGER-2443)), policy version and security zone in audit
  records ([RANGER-2340](https://issues.apache.org/jira/browse/RANGER-2340), [RANGER-2296](https://issues.apache.org/jira/browse/RANGER-2296)), import/export by zone ([RANGER-2351](https://issues.apache.org/jira/browse/RANGER-2351)), a tag service created automatically with each resource service ([RANGER-2481](https://issues.apache.org/jira/browse/RANGER-2481)).
