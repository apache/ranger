# Apache Ranger 2.6.0 release notes

Apache Ranger 2.6.0 was released on February 15, 2025. The release adds import and export of individual policies, moves the embedded web server to Tomcat 9, reduces plugin memory use, and extends the docker setup to Oracle, SQL Server and Ozone.

The cwiki page for this release lists JIRA keys only; the summaries in the tables below were taken from JIRA for the same keys.

## Highlights

- **Import and export individual policies** from the Admin UI and REST API ([RANGER-4936](https://issues.apache.org/jira/browse/RANGER-4936)).
- **Policy engine** — less memory to build the engine ([RANGER-4905](https://issues.apache.org/jira/browse/RANGER-4905)), trie traversal enhancements ([RANGER-4893](https://issues.apache.org/jira/browse/RANGER-4893), [RANGER-4922](https://issues.apache.org/jira/browse/RANGER-4922)), rationalized match types for
  policy and tag evaluation ([RANGER-4990](https://issues.apache.org/jira/browse/RANGER-4990)), denials for descendant resources ignored where appropriate ([RANGER-5001](https://issues.apache.org/jira/browse/RANGER-5001)), validity-schedule
  policy condition ([RANGER-4970](https://issues.apache.org/jira/browse/RANGER-4970)), authorization of multiple accesses grouped by access groups in one call ([RANGER-4820](https://issues.apache.org/jira/browse/RANGER-4820)).
- **Federated users** — a new user type for external users coming from data sharing ([RANGER-5008](https://issues.apache.org/jira/browse/RANGER-5008), [RANGER-4973](https://issues.apache.org/jira/browse/RANGER-4973), [RANGER-4972](https://issues.apache.org/jira/browse/RANGER-4972)).
- **HBase plugin** — configurable authorization level: table, column family or column ([RANGER-4670](https://issues.apache.org/jira/browse/RANGER-4670)).
- **Platform** — embedded Tomcat upgraded from 8.5.x to 9.x ([RANGER-4892](https://issues.apache.org/jira/browse/RANGER-4892)), Hadoop 3.3.6 ([RANGER-4904](https://issues.apache.org/jira/browse/RANGER-4904)), Spring 5.3.39 ([RANGER-4912](https://issues.apache.org/jira/browse/RANGER-4912)), Atlas 2.4.0 ([RANGER-5095](https://issues.apache.org/jira/browse/RANGER-5095)).
- **Plugins** use session cookies for all REST calls when available ([RANGER-4908](https://issues.apache.org/jira/browse/RANGER-4908)) and can load extra configuration files and a Kerberos
  identity at initialization ([RANGER-5103](https://issues.apache.org/jira/browse/RANGER-5103), [RANGER-5116](https://issues.apache.org/jira/browse/RANGER-5116)).
- **Operations** — utility to migrate admin audit logs from `x_trx_log` to `x_trx_log_v2` ([RANGER-4809](https://issues.apache.org/jira/browse/RANGER-4809)), configuration for the
  `ranger-common-ha` module ([RANGER-4879](https://issues.apache.org/jira/browse/RANGER-4879)) and a fix so only one UserSync/TagSync instance is active ([RANGER-4520](https://issues.apache.org/jira/browse/RANGER-4520)), LDAP sync interval no longer
  capped at one hour ([RANGER-4307](https://issues.apache.org/jira/browse/RANGER-4307)), audit REST API can return event time in a chosen time zone ([RANGER-4992](https://issues.apache.org/jira/browse/RANGER-4992)).
- **Docker** — Oracle ([RANGER-5073](https://issues.apache.org/jira/browse/RANGER-5073)) and SQL Server ([RANGER-5080](https://issues.apache.org/jira/browse/RANGER-5080)) databases, Ozone ([RANGER-3801](https://issues.apache.org/jira/browse/RANGER-3801)), UBI 9 base image ([RANGER-3746](https://issues.apache.org/jira/browse/RANGER-3746)).
